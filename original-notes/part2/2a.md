# Sandboxing

## Lines of defense

- First: prevent attack
- Second: minimize impact of attack

## Reference Monitors

check accesses to different objects.

**NEAT property**

- Non-bypassable
- Evaluable
- Always invoked
- Tamper-proof

## 3 Security Principles

- Separation of Concerns
  - policy vs enforcement
- Minimize Trusted Computing Base (TCB)
  - lecture note said C for code
- Least Privilege
  - only give the minimum privilege needed to perform a task
